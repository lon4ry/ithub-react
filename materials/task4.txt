КТ 4. Практическое задание: Работа с API и Zustand
Дисциплина: 3291.РВП.F «Разработка веб-приложений (React)» · Раздел 4 «Работа с API и управление состоянием (Zustand)» · Тема 4.4
Описание задания
Студент подключает Axios для типизированных запросов к реальному Python FastAPI бэкенду, реализует паттерн loading/error/data для обработки состояний запроса и настраивает глобальное хранилище через Zustand, объединяя инструменты разделов 4.1–4.3 в единую рабочую архитектуру.
Технические требования
	•	Настроен типизированный Axios-клиент (axios.create с baseURL), используемый для запросов к реальному FastAPI-серверу.
	•	TypeScript-интерфейсы данных соответствуют Pydantic-схемам бэкенда — поля и типы совпадают (с учётом конвенций именования).
	•	Состояние запроса представлено через дискриминированный union (idle / loading / error / success) или эквивалентную конструкцию, исключающую невозможные комбинации флагов.
	•	Создано минимум одно Zustand-хранилище с типизированным интерфейсом, инкапсулирующее как данные, так и функцию их загрузки.
	•	Все три состояния запроса (загрузка, ошибка, успех) визуально отображены в интерфейсе и проверены на практике.
	•	CORS настроен на бэкенде, приложение работает при одновременном запуске фронтенда и FastAPI-сервера.
