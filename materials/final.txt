КТ 6. Финальный проект: Fullstack React + TypeScript + Python API
Дисциплина: 3291.РВП.F «Разработка веб-приложений (React)» · Раздел 6 «Финальный проект» · Тема 6.2
Описание задания
Студент самостоятельно проектирует и реализует Fullstack-приложение на React + TypeScript, подключённое к реальному Python FastAPI бэкенду из курса «Python для React». Тема свободная (каталог товаров, список задач, блог-платформа и т.п.), но приложение должно объединять все инструменты, изученные в разделах 1–6 курса: типизированные компоненты, роутинг, работу с API и Zustand, авторизацию по JWT и единый подход к стилизации.
Технические требования
	•	Проект создан на Vite с шаблоном React + TypeScript, запускается командой npm run dev без ошибок в консоли.
	•	Реализовано не менее 4 маршрутов через React Router, включая минимум один динамический маршрут с типизированным параметром (useParams) и страницу 404.
	•	Один из маршрутов защищён через PrivateRoute и недоступен без авторизации — проверяется прямым переходом по адресу, а не только скрытием ссылки.
	•	Все запросы к FastAPI-бэкенду выполняются через типизированный Axios-клиент с baseURL; TypeScript-интерфейсы данных соответствуют Pydantic-схемам бэкенда.
	•	Состояние каждого запроса представлено через паттерн loading/error/data (дискриминированный union или эквивалент), все три состояния отображены в интерфейсе.
	•	Реализовано минимум одно Zustand-хранилище с типизированным интерфейсом для данных, не связанных напрямую с авторизацией.
	•	Реализована форма входа с валидацией, сохранением JWT-токена, axios request- и response-interceptors, корректным выходом с очисткой токена.
	•	Стилизация выполнена единообразно: либо CSS Modules, либо Tailwind CSS — без смешивания подходов между компонентами без необходимости.
