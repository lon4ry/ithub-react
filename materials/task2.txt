Тема 2.5. Context API: передача данных через дерево компонентов
Дисциплина: Разработка веб-приложений (React) (3291.РВП.F)
Тип задания
Практическое (контрольная точка, итог раздела 2)
Максимальный балл
10 баллов
Формат сдачи
Папка React + TypeScript проекта с AuthContext и связанными компонентами
Инструменты
React 18, TypeScript, Vite

Описание задания
Создайте AuthContext — типизированный контекст авторизации, объединяющий все темы раздела 2: состояние (useState), побочные эффекты (useEffect), переиспользуемую логику (custom hooks) и передачу данных через дерево (Context API).

Требования к проекту
1. Типизированный AuthContext
Context содержит поля user (тип объект с минимум id и name, либо null) и функции login(name: string) и logout().
2. AuthProvider с состоянием
Provider управляет состоянием через useState, передаёт значение через value в Context.Provider.
3. Кастомный хук useAuth
Хук оборачивает useContext, проверяет на undefined и выбрасывает понятную ошибку при использовании вне Provider.
4. Использование без prop drilling
Минимум 3 компонента на разной глубине дерева получают данные через useAuth(), без передачи через props промежуточных компонентов.
5. Условный рендеринг на основе user
Минимум один компонент отображает разный JSX в зависимости от того, авторизован пользователь или нет.
6. Восстановление состояния через useEffect
AuthProvider использует useEffect для восстановления пользователя при загрузке приложения (например, из localStorage).
